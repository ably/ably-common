---
code: 104008
identifier: pipe_failed
title: Pipe failed
summary: An AI Transport pipe stopped before reaching the end of its source. The source threw, an event could not be encoded, Ably rejected a write, or a streamed message could not be repaired.
---

## What you should do

Inspect the `cause` to find out what failed and check its error code. If the source threw, the model or provider failed. Generate the reply again. If the error came from Ably or the codec, fix that problem first. A retry will fail the same way.

The partial reply stays on the channel. The pipe does not end any stream it had open.

## Why it happens

A pipe reads events from a source, such as a model's stream. It writes each event to the channel as it arrives.

The pipe stops at the first failure. This can happen if the source throws, the codec cannot encode an event, or Ably rejects a publish or update. It also happens if an append fails and the SDK cannot repair the streamed message.

Before stopping, the pipe flushes and repairs what it has written. The original error is preserved as the `cause`.

## What you'll see

The error is reported with code 104008 and status 500. Messages take the form `unable to pipe; source failed: ...`, `unable to pipe; encode failed for event ...`, `unable to pipe; write failed for event ...`, or `unable to pipe; repair failed: ...`.
