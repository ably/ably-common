---
code: 40036
identifier: client_id_too_long
title: Client ID too long
summary: A publish was rejected because the client ID of a message, presence message, object message or annotation exceeded the maximum permitted length. The client ID may have been set explicitly or inherited from the connection.
---

## What you should do

Use a shorter client ID. Client IDs are limited to 100 bytes by default. If you want to derive a client ID from a longer value, consider using a fixed-length hash of that value. If you have a good reason for needing to exceed this limit, please talk to us at https://ably.com/support.

## Why it happens

Every message, presence message, object message and annotation carries the client ID of its publisher, either set explicitly on the message or inherited from the client ID of the connection or request. Ably by default limits the length of client IDs.

## What you'll see

The error is reported with code 40036 and HTTP status 400. The message is of the form `clientId length (150 bytes) exceeds maximum of 100 bytes`.
