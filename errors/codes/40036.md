---
code: 40036
identifier: stream_closed
title: Write to a closed stream
summary: A write was refused because the stream or writer it was made to had already been closed, so nothing was published for it. A closed stream or writer accepts no more writes.
---

## What you should do

Make every write before you close the stream or writer. To carry on writing after a close, open a new writer, or a new stream on the same message, and make the write there. The closed one does not reopen.

## Why it happens

Closing a stream or writer waits for the writes already made to apply, then refuses any write made after it. A write made after the close was called, for example from a callback that fires late or from code that keeps a reference to the closed writer, is refused with this error rather than being dropped silently.

## What you'll see

The error is reported with code 40036 and HTTP status 400. In the Ably AI Transport JavaScript SDK, the message is `unable to write event; the writer is closed`.
