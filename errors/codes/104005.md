title: Write failed
summary: An AI Transport publish or update to the channel was refused, or, in the Vercel chat transport, the HTTP POST to the agent endpoint failed or returned a non-2xx response.
---

## What you should do

This fails in one of two ways:

- **The channel refused a write**, made by an agent adaptor's `send` or by an event writer. Inspect the `cause`, which carries the channel's own error and its error code, for what went wrong and how to fix it. An event writer stops at the failure, so open a new writer to carry on.
- **The Vercel chat transport's HTTP POST failed.** The request to your agent endpoint returned a non-2xx response, surfaced with the status the endpoint returned, or errored outright. Check that the endpoint is reachable and returns a 2xx.

Neither is retried automatically, so make the write again once the underlying problem is resolved.

## Why it happens

An adaptor's `send` publishes one message to the channel, and an event writer publishes, appends to, and updates messages as events arrive. In the Vercel chat transport a send instead POSTs to your agent endpoint, which publishes on the agent's behalf. This error is the non-permission failure of any of these paths. A permission failure is reported separately as a capability error. The originating failure is preserved as the `cause` where available.

## What you'll see

The error is reported with code 104005. Its status is 500 for a refused channel write; for a non-2xx POST it is the status the agent endpoint returned. Messages take the form `unable to publish; ...`, `unable to update; ...`, or `unable to send messages; ...`.
