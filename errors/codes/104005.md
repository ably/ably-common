---

## What you should do

This fails in one of two ways:

- **The channel refused a message an agent adaptor's `send` published.** Inspect the `cause`, which carries the channel's own error and its error code, for what went wrong and how to fix it.
- **The Vercel chat transport's HTTP POST failed.** The request to your agent endpoint returned a non-2xx response, surfaced with the status the endpoint returned, or errored outright. Check that the endpoint is reachable and returns a 2xx.

Neither is retried automatically, so send again once the underlying problem is resolved.

## Why it happens

An adaptor's `send` publishes one message to the channel. In the Vercel chat transport a send instead POSTs to your agent endpoint, which publishes on the agent's behalf. This error is the non-permission failure of either path. A permission failure is reported separately as a capability error. The originating failure is preserved as the `cause` where available.

## What you'll see

The error is reported with code 104005. Its status is 500 for a refused publish; for a non-2xx POST it is the status the agent endpoint returned. Messages take the form `unable to publish; ...` or `unable to send messages; ...`.
