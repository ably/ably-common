code: 92000
identifier: invalid_object_message
title: Invalid LiveObjects message
summary: A LiveObjects message was rejected because it was invalid or did not conform to the expected structure. This usually indicates a problem with how the object operation was constructed before it was sent.
---

## What you should do

Send a well-formed object operation. This means the fix is in how the operation was built rather than in retrying it. If you construct object operations yourself rather than through the [LiveObjects](https://ably.com/docs/liveobjects) API, check them against what that API produces.

## Why it happens

An object message did not conform to the structure Ably expects. Causes include a malformed object identifier, an unrecognized operation or message action, or a missing required field.

## What you'll see

The error is reported with code 92000 and HTTP status 400. The message describes what was invalid, for example `invalid object message: object operation required` or `invalid object message: invalid object id: ...`.
