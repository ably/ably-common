code: 93004
identifier: annotation_target_message_deleted
title: Annotation on a deleted message
summary: An annotation was rejected because the message it referenced had been deleted. Annotations that remove an existing annotation from a deleted message are still accepted.
---

## What you should do

Don't annotate messages that have been deleted. If a client may annotate a message around the time it is deleted, treat this error as meaning the message is gone.

## Why it happens

Once a message has been [deleted](https://ably.com/docs/messages/updates-deletes), new [annotations](https://ably.com/docs/messages/annotations) to it are refused. Deleting an existing annotation is still allowed, so clients can remove annotations they made before the message was deleted.

Note that this behaviour is not a hard guarantee: due to the nature of concurrent operations in multiple regions, you may well be able to publish an annotation for a short time after a delete has been accepted. In this case, the annotation will still be stored even though you will not get a summary for it, and if the message is subsequently undeleted, its summary will eventually incorporate that annotation.

## What you'll see

The error is reported with code 93004 and HTTP status 400. The message is of the form `Unable to add annotation: message <serial> has been deleted`.
