---

## What you should do

This is an unexpected error inside Ably rather than a problem with your request, so retrying after a short delay is reasonable. If it persists, [contact Ably support](https://ably.com/docs/platform/support) with your app ID and roughly when it occurred.

## Why it happens

An operation on a connection failed because of an unexpected error inside the Ably platform.

## What you'll see

The error is reported with code 50002 and HTTP status 500. The message is typically `Internal connection error`.
