title: SDK version not compatible with MAU pricing
summary: A connection or request was refused because it came from a version of an Ably SDK that is not compatible with monthly active user (MAU) pricing, which the account uses.
---

## What you should do

Replace the SDK with the package the message names, at the version it gives or later. Where there is both a device and a server package, use the device package in apps that run on end users' devices and the server package on your own servers. Retrying with the same version does not help.

| SDK | Replace with | Minimum version |
|---|---|---|
| Ably Pub/Sub JavaScript SDK (`ably` npm package) | `@ably/pubsub-device` on devices, `@ably/pubsub-server` on servers | 3.0.0 |
| Ably Pub/Sub Go SDK (`github.com/ably/ably-go`) | `github.com/ably/ably-pubsub-go/v2`, importing `device/pubsub` on devices or `server/pubsub` on servers | v2.0.0 |
| Ably Pub/Sub Swift and Objective-C SDK (`ably-cocoa`) | The `AblyPubSubDevice` product of `ably-pubsub-cocoa`, for devices only | 2.0.0 |
| Ably Pub/Sub Java and Android SDKs (`ably-java`, `ably-android`) | `io.ably.pubsub:device` on devices, `io.ably.pubsub:server` on servers | 2.0.0 |
| Ably Pub/Sub .NET SDK (`ably.io` NuGet package) | `Ably.PubSub.Device` on devices, `Ably.PubSub.Server` on servers | 2.0.0 |
| Ably Pub/Sub Python SDK (`ably` PyPI package) | `ably-pubsub-server`, for servers only | 4.0.1 |
| Ably Pub/Sub Ruby SDK (`ably` or `ably-rest` gem) | The `ably-pubsub-server` gem, for servers only | 2.0.0 |
| Ably Pub/Sub PHP SDK (`ably/ably-php`) | `ably/pubsub-server`, for servers only | 2.0.0 |
| Ably Pub/Sub Flutter SDK (`ably_flutter`) | `ably_pubsub_device_flutter`, for devices only | 2.0.0 |

If you already use the Python `ably-pubsub-server` 4.0.0, upgrade it to 4.0.1, because 4.0.0 does not identify itself as a server.

If you use an SDK or tool built on a Pub/Sub SDK, upgrade it to at least the version below, because earlier versions can't use the new packages. Where you install the Pub/Sub SDK alongside it yourself, replace that too, as in the table above:

| SDK or tool | Minimum version |
|---|---|
| Ably Chat JavaScript SDK (`@ably/chat`) | 2.0.0 |
| Ably Spaces SDK (`@ably/spaces`) | 0.6.0 |
| Ably AI Transport SDK (`@ably/ai-transport`) | 0.11.0 |
| Ably Chat Kotlin SDK (`com.ably.chat:chat`) | 2.0.0 |
| Ably Chat Swift SDK (`ably-chat-swift`) | 2.0.0 |
| Ably CLI (`@ably/cli`) | 2.0.0 |
| Ably Kafka Connector (`kafka-connect-ably`) | 4.2.0 |
| Ably Laravel Echo (`@ably/laravel-echo`), which installs `@ably/pubsub-device` itself, so remove the `ably` npm package | 1.1.0 |
| Ably Laravel Broadcaster (`ably/laravel-broadcaster`), which uses `ably/pubsub-server` | 1.1.0 |

There is no compatible release of `ably/ably-php-laravel`. Move to `ably/laravel-broadcaster` 1.1.0 or later, or use `ably/pubsub-server` 2.0.0 or later directly.

## Why it happens

Under MAU pricing, Ably counts each end user's device toward the account's monthly active users, but not your own servers, so it needs to know which of the two each client is. Versions of Ably SDKs that are compatible with MAU pricing provide separate device and server packages so Ably can tell them apart. Earlier versions don't, and nor do SDKs built on them, such as earlier versions of the Chat or Spaces SDKs, so their connections and requests are refused.

## What you'll see

The error is reported with code 40168 and HTTP status 400. The message starts `This version of the Ably SDK is not compatible with your account, which uses MAU pricing.`, followed by what to use instead of the SDK that sent the connection or request. For the Ably Pub/Sub JavaScript SDK, for example, the message is `This version of the Ably SDK is not compatible with your account, which uses MAU pricing. Use @ably/pubsub-device 3.0.0+ on end-user devices or @ably/pubsub-server 3.0.0+ on servers, instead of the ably npm package.`

When Ably doesn't recognize the SDK, the message is `This version of the Ably SDK is not compatible with your account, which uses MAU pricing. Upgrade to the latest version that is listed as compatible with MAU pricing. See https://ably.com/docs/sdks`
